# Aula Fácil — descargas

Aula Fácil es una app para maestros: lista, asistencia, calificaciones, boletas y más, funciona sin internet y tus datos se quedan en tu equipo.

- Descargar e instalar: https://aula-facil-relutech.netlify.app/descargar
- Dudas o claves Premium por WhatsApp: [222 306 0367](https://wa.me/522223060367)

Este repositorio solo aloja los instaladores (ver *Releases*). No contiene código fuente.

## Cómo instalar

- **Windows 10/11:** descarga `Aula-Facil-Windows.zip`, clic derecho → «Extraer todo» y da doble clic en «Abrir Aula Facil.vbs» (o «Abrir Aula Facil.bat»). La primera vez, si Windows muestra un aviso: «Más información» → «Ejecutar de todas formas» (o «Abrir»).
- **Mac (macOS 12+):** descarga `Aula-Facil-Mac.zip`, descomprímelo y da doble clic en «Aula Fácil.app» (o «Abrir Aula Facil.command»). Deja la carpeta «aula-facil» completa (por ejemplo en Documentos). La primera vez, si macOS dice que no puede abrirla: clic derecho → «Abrir» → «Abrir» (macOS 15: Ajustes del Sistema → Privacidad y seguridad → «Abrir de todas formas»).
- **Android o tablet:** abre https://aula-facil-relutech.netlify.app en el navegador. Android (Chrome): menú ⋮ → «Instalar app». Tablet o celular con Safari: Compartir → «Agregar a inicio».
- **Portátil (Windows y Mac en una carpeta):** `Aula-Facil-Portable.zip`; abre con «Abrir Aula Facil.bat» o «Abrir Aula Facil.command».

Conteo de descargas: cada archivo de *Releases* muestra cuántas veces se descargó.
